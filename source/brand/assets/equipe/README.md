# Team gallery photos

Originals for the homepage's team photo carousel (bottom of "Notre équipe"). Drop
photos here (GitHub web UI: "Add file" → "Upload files"); Claude copies them into
`site/public/images/equipe/`, which the carousel reads automatically at build time -
any image file found there becomes a slide, in no particular required order, no code
changes needed.

Landscape, roughly 2:1 (e.g. ~1900x950px), JPG or PNG. Any number of photos - add or
remove freely.
